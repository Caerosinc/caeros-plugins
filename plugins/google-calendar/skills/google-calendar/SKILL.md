# Google Calendar

Use Google Calendar app tools for availability and event work.

- Read the relevant calendar and timezone before proposing or changing a time.
- Confirm attendees, timezone, duration, and recurrence before creating an event.
- Treat create, update, attendee, and delete actions as approval-gated.
- Never claim an event changed until the tool returns success.
