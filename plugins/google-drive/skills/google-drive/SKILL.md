# Google Drive

Use the Google Drive app tools for user-owned Drive content.

- Prefer find, get, and list tools before mutations.
- Confirm the exact destination before moving, copying, or uploading a file.
- Treat create, update, move, upload, and delete operations as approval-gated.
- Never claim a file changed until the tool returns success.
